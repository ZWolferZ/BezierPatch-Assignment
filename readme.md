# **Compiling**

## ***For Windows:***

##### 

##### Simply run either the windows\_compile.bat or the windows\_compile\_and\_run.bat

## ***For Redhat-Linux:***

##### Open a terminal (or navigate to) inside the Linux - Redhat Build, and run the following commands

1. ##### chmod +x redhat\_compile\_and\_run.sh or chmod +x redhat\_compile.sh
2. ##### ./redhat\_compile\_and\_run.sh or ./redhat\_compile.sh
